# Установка CRM «Клиенты» — пошаговая инструкция

Вся система живёт в вашем Google-аккаунте: таблица хранит данные, скрипт обеспечивает логику, интерфейс открывается в браузере. Ничего устанавливать на компьютер не нужно, оплата Google не требуется.

Установка занимает 10–15 минут и делается один раз.

---

## Шаг 1. Создайте таблицу

1. Откройте [sheets.new](https://sheets.new) в браузере, где вы вошли в свой Google-аккаунт.
2. Дайте таблице понятное имя, например **«CRM Клиенты»** (вкладка внизу или поле сверху слева).

## Шаг 2. Откройте редактор скриптов

1. В таблице выберите меню **Расширения → Apps Script**.
2. Откроется новая вкладка с редактором кода.

## Шаг 3. Загрузите файлы проекта

В редакторе слева находится список файлов. Вам нужно создать в нём файлы с точно такими же именами, как в этой папке:

| Файл проекта | Как создать в редакторе |
|---|---|
| `Code.gs` | уже существует под именем `Код.gs` (Code.gs) — просто откройте его |
| `appsscript.json` | кнопка **＋** → **Скрипт (в настройках)** — но проще пункт «Настройки проекта» слева → включите галочку **«Показать файл манифеста appsscript.json»** |
| `Index.html` | кнопка **＋** → **HTML** → имя `Index` |
| `Styles.html` | кнопка **＋** → **HTML** → имя `Styles` |
| `JavaScript.html` | кнопка **＋** → **HTML** → имя `JavaScript` |

Дальше:

1. Откройте каждый файл из этой папки в любом текстовом редакторе (Блокнот подойдёт), выделите всё (Ctrl+A), скопируйте (Ctrl+C).
2. В редакторе Apps Script откройте файл с тем же именем, удалите его содержимое и вставьте скопированное (Ctrl+A, Ctrl+V).
3. Повторите для всех пяти файлов. Имена файлов в редакторе должны совпадать **точно** (с учётом регистра): `Index`, `Styles`, `JavaScript`.
4. Откройте `appsscript.json` (через настройки проекта, как описано выше) и вставьте содержимое одноимённого файла из этой папки, заменив то, что там было.
5. Нажмите **Сохранить всё** (иконка дискеты, Ctrl+S).

## Шаг 4. Разверните веб-приложение

1. Справа вверху нажмите синюю кнопку **Развернуть → Новое развёртывание**.
2. Нажмите на шестерёнку рядом с «Тип приложения» и выберите **Веб-приложение**.
3. Заполните поля:
   - **Описание**: можно оставить пустым или написать «CRM v1».
   - **Выполнять как**: **Меня** (ваш аккаунт).
   - **Кому доступно**: **Только я сам** — интерфейс будет открываться только под вашим аккаунтом.
4. Нажмите **Развернуть**.
5. Google попросит разрешить доступ:
   - нажмите **Проверить разрешения**;
   - выберите ваш аккаунт;
   - если появится предупреждение «Приложение не проверено» — нажмите **Дополнительные сведения → Перейти на страницу (небезопасно)**. Это нормально: скрипт создали вы сами, для себя.
   - нажмите **Разрешить** (скрипт получит доступ к этой таблице и возможность делать внешние запросы — они нужны для Instagram и экспорта в Excel).
6. Появится окно с **ссылкой на веб-приложение** — скопируйте её и сохраните. Это и есть адрес вашей CRM.

## Шаг 5. Откройте CRM

1. Перейдите по скопированной ссылке.
2. При первом открытии скрипт сам создаст в таблице три листа: **Клиенты**, **Комментарии** и **Настройки** — и заполнит «Настройки» стартовыми категориями и статусами.
3. Нажмите **«Добавить»** и создайте первого клиента. Готово!

### На телефоне

Откройте ту же ссылку в браузере телефона и добавьте её на главный экран (в Chrome: меню ⋮ → «Добавить на главный экран»). CRM будет запускаться как приложение.

## Как пользоваться

**Добавление клиента**
- Кнопка **«Добавить»** → вставьте Instagram-ссылку (или просто ник) в поле автозаполнения → **«Получить данные»** → ник, имя, фото и биография подставятся автоматически. Если Instagram не ответил, поля заполнятся только ником и ссылкой — остальное можно вписать вручную.
- Можно добавлять и без Instagram — достаточно имени или ника.

**Карточка клиента** — нажмите на карточку в списке. Внутри: все поля на редактирование, комментарии и даты. Кнопка **«Удалить»** убирает клиента вместе с его комментариями.

**Моя оценка клиента** — блок в карточке клиента:
- **«Насколько нравится»** — кликните по звёздам (1–5). Повторный клик по той же звезде или крестик сбрасывают оценку.
- **«Доход за сеанс, ₽»** — сколько по ощущениям можно получить за один сеанс с этим клиентом.
- **«Татуировок сделано»** — сколько татуировок клиенту уже сделано.

Заполненные оценки видны прямо на карточке в списке: ★ 4 · ~5 000 ₽ · 3 тату.

**Поиск и фильтры** — строка поиска ищет по всем полям сразу; выпадающие списки фильтруют по категории и статусу.

**Экспорт в Excel** — кнопка **«Экспорт»** в шапке скачивает файл .xlsx со всеми листами таблицы.

**Свои категории и статусы** — откройте таблицу, лист **«Настройки»**, и отредактируйте списки в колонках «Категории» и «Статусы». Интерфейс подхватит их автоматически (обновите страницу CRM).

**Новые колонки в таблице** — при обновлении кода CRM новые поля (например, «Нравится (1–5)», «Доход за сеанс (₽)», «Татуировок сделано») добавляются в лист «Клиенты» автоматически при первом открытии веб-приложения: колонки дописываются справа, существующие данные не трогаются. Ничего вручную делать не нужно.

**Прямой доступ к данным** — таблица всегда содержит полную копию базы: лист «Клиенты» — все клиенты, лист «Комментарии» — все комментарии с датами. Правки вручную в таблице тоже появятся в интерфейсе (обновите страницу).

## Обновление версии

Если вы изменили код (или попросили меня что-то доработать):

1. Замените содержимое файлов в редакторе Apps Script и сохраните.
2. **Развернуть → Управление развёртываниями → карандаш (изменить) → Версия: «Новая версия» → Развернуть.**
3. Ссылка на приложение останется прежней.

---

## Важные мелочи

- **Не переименовывайте** листы «Клиенты», «Комментарии», «Настройки» и заголовки колонок в них — скрипт ищет данные по этим именам. Названия самих категорий и статусов менять можно и нужно.
- **Автозаполнение из Instagram** работает через бесплатные публичные методы Instagram: иногда Instagram временно блокирует запросы (особенно подряд один за другим). Тогда данные не подставятся — попробуйте через минуту или заполните поля вручную. Код написан так, что позже к нему можно подключить платный API без переделки остальной системы.
- Если при открытии CRM появляется ошибка «В таблице нет листа…» — просто обновите страницу: лист создастся автоматически.

## Состав файлов проекта

| Файл | Что это |
|---|---|
| `Code.gs` | серверная логика: база, комментарии, настройки, Instagram, экспорт |
| `Index.html` | разметка интерфейса |
| `Styles.html` | оформление (адаптивное, работает на телефоне) |
| `JavaScript.html` | поведение интерфейса: поиск, фильтры, модальные окна, скачивание экспорта |
| `appsscript.json` | настройки проекта Apps Script (права доступа) |
| `tests/` | автоматические тесты — в Google не загружаются, для разработки |
