## Задача

Добавить в CRM три новых поля клиента (субъективная оценка клиента мастером):
1. **«Нравится»** — насколько нравится клиент, звёзды 1–5 (кликабельные звёзды в форме, ★ на карточке).
2. **«Доход за сеанс (₽)»** — сколько по ощущениям можно получить за один сеанс (число, на карточке отображается как «~5 000 ₽»).
3. **«Татуировок сделано»** — счётчик татуировок, сделанных клиенту.

Новые поля показываются и в форме карточки, и компактной строкой на карточках в списке: `★ 4 · ~5 000 ₽ · 3 тату`.

## Реализация

Ключи полей: `likeLevel`, `sessionMoney`, `tattooCount`.

### 1. `Code.gs`
- **`CLIENT_FIELDS` (строки 14–29):** добавить 3 записи **в конец** массива (после `updated`) — это сохранит соответствие колонок уже существующего листа «Клиенты», а индексы колонок дат `[1, 13]` в `ensureSetup_` останутся корректными:
  - `{ key: 'likeLevel', header: 'Нравится (1–5)' }`
  - `{ key: 'sessionMoney', header: 'Доход за сеанс (₽)' }`
  - `{ key: 'tattooCount', header: 'Татуировок сделано' }`
- **Миграция заголовков в `ensureSheet_` (строки 87–102):** сейчас заголовки пишутся только в пустой лист, поэтому у уже развёрнутой таблицы новые колонки не появятся. Добавить: если лист существует и его строка заголовков короче ожидаемой — дописать недостающие заголовки в следующие пустые ячейки первой строки (с тем же жирным шрифтом и фоном). Чужие/переименованные пользователем колонки не трогаем. После этого при следующем открытии веб-приложения колонки добавятся автоматически, вручную таблицу править не нужно.
- `getClients`/`saveClient`/`exportXlsx` обходят `CLIENT_FIELDS` циклом — изменений не требуют.

### 2. `Index.html`
В форме `#client-form` после блока `.grid2` добавить секцию «Оценка» :
- Строка из 5 кнопок-звёзд (SVG-звёзды, как остальные иконки проекта) + скрытый `<input id="f-like">` для значения 1–5 + маленькая кнопка «сбросить» (×). Повторный клик по той же звезде тоже сбрасывает оценку.
- `<input id="f-money" type="number" min="0" step="any">` с подписью «₽» и подсказкой «Сколько по ощущениям можно получить за сеанс».
- `<input id="f-tattoos" type="number" min="0" step="1">` — количество сделанных татуировок.

### 3. `JavaScript.html`
- **`openClientModal` (~199):** заполнение `f-like` (и подсветка звёзд), `f-money`, `f-tattoos` значениями клиента или пустыми для нового клиента.
- **`saveFromForm` (~327):** включить `likeLevel`, `sessionMoney`, `tattooCount` в объект клиента.
- Обработчики клика по звёздам (делегирование на контейнере) с обновлением скрытого input и подсветки.
- **`cardHtml` (~107):** компактная строка статистики после `card-meta` — только из заполненных полей: `★ 4 · ~5 000 ₽ · 3 тату`. Деньги форматировать через `toLocaleString('ru-RU')`; если введено не число — показывать как есть.
- **Поиск (~72):** добавить новые поля в `haystack`.

### 4. `Styles.html`
Стили для строки звёзд (заполненная/пустая, hover) и строки статистики на карточке (`.card-stats`), суффикс «₽» у поля денег.
