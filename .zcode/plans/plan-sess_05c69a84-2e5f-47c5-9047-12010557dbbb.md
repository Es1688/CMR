# Облачная CRM на Google Sheets + Google Apps Script (базовая версия)

## Архитектура
Google Sheet (хранилище) → Apps Script веб-приложение (логика) → браузерный интерфейс на русском, адаптированный под телефон и компьютер. Без сервера, хостинга и БД.

## Структура таблицы (создаётся скриптом автоматически при первом открытии)
- **«Клиенты»** — колонки: ID, Дата добавления, Имя, Instagram-ник, Instagram-ссылка, Аватар (URL), Биография, Телефон, Email, Категория, Статус, Город, Примечания, Дата изменения
- **«Комментарии»** — ID записи, ID клиента, Дата и время, Автор, Текст
- **«Настройки»** — редактируемые списки категорий и статусов (дефолтные статусы: Новый, В работе, Ожидание, Сделка, Отказ) — фильтры и выпадающие списки интерфейса берутся отсюда, код править не нужно

## Файлы проекта (в /home/egor/work/it/kwork/Kutuncev)
1. `appsscript.json` — манифест с OAuth-областями (таблицы + внешние запросы)
2. `Code.gs` — серверная логика:
   - `doGet()` — отдаёт интерфейс; `ensureSetup_()` — автосоздание листов/заголовков/настроек
   - `getClients()`, `saveClient()` (создание/обновление по UUID + проставление дат), `deleteClient()`
   - `getComments()` / `addComment()` — лента комментариев по клиенту
   - `getSettings()` — категории и статусы из листа «Настройки»
   - `fetchInstagramData()` — ник/имя/аватар/био по ссылке, **бесплатным способом с цепочкой фолбэков**: (1) публичный эндпоинт `web_profile_info` с заголовком `x-ig-app-id` → (2) парсинг og:meta страницы профиля → (3) только ник и ссылка + сообщение «заполните вручную». Код изолирован в одну функцию, чтобы позже можно было подключить платный API без переделки остального
   - `exportXlsx()` — выгрузка базы в .xlsx через export-эндпоинт с OAuth-токеном, файл отдаётся в браузер напрямую (без прав на Drive)
3. `Index.html` — разметка (шапка с поиском, фильтры «Категория»/«Статус», кнопки «Добавить клиента» и «Экспорт в Excel», список клиентов-карточек, модалки добавления и карточки клиента)
4. `Styles.html` — адаптивный CSS (на телефоне — карточки в одну колонку)
5. `JavaScript.html` — клиентская логика (поиск, фильтры, автозаполнение из Instagram с предпросмотром, редактирование, комментарии, скачивание экспорта)
6. `ИНСТРУКЦИЯ.md` — пошаговая установка для заказчика без программирования: создать таблицу → Расширения → Apps Script → вставить файлы → Развернуть как веб-приложение («выполнять от моего имени», «доступ только мне» — доступ только владелец) → открыть ссылку, добавить на главный экран телефона

## Возможности v1
Добавление клиента вручную и по Instagram-ссылке с автозаполнением (ник, имя, аватар, био), карточка клиента с редактированием всех полей, поиск по базе, фильтры по категории и статусу, комментарии с датами, экспорт в Excel, мобильная версия. Google Sheets остаётся полной копией базы — им можно пользоваться и напрямую.

## Проверка
- Локально через Node: синтаксическая проверка JS/HTML-скриптов и юнит-тесты чистых функций (извлечение ника из любой формы ссылки/ника, парсинг og:meta, парсинг JSON web_profile_info)
- Финальную проверку Instagram-функции выполним на реальных ссылках после деплоя — в коде заложены фолбэки и понятные сообщения, если Instagram не отдал данные
- Деплой в аккаунт заказчика с его стороны по инструкции (у меня доступа к его Google-аккаунту нет)
